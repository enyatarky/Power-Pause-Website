# Power Pause Interactive Website

This repository contains the code for my Programming & Development project.

## Project description

Power Pause is a movement-based office card game that helps office workers take short, structured and playful movement breaks during their workday.

For this course, I will create a responsive one-page website that explains the Power Pause concept and includes a simple interactive break recommendation tool.

## Course choice

I chose Course A: Custom Coding because I already have some experience with WordPress and want to learn the basics of HTML, CSS, JavaScript and GitHub.
